# CSS Practice

A collection of CSS practice files, examples, and exercises created during Web Technologies (IWT) coursework.

## Topics Covered
- **Basic Styling & Selectors**: Element selectors, Class (`class.html`), ID (`id.html`, `idborder.html`), Grouping (`group.html`), Child selectors (`child.html`)
- **CSS Embedding Methods**: Inline, Internal/Embedded (`embedded.html`), External stylesheets (`external.html`, `external.css`)
- **Box Model & Layout**: Borders (`border.html`), Display properties (`display.html`), Div layout (`div.html`), Containers (`container.html`)
- **Typography & Formatting**: Fonts (`font.html`), Text decoration (`decoration.html`), Lists (`list.html`)
- **Media & Images**: Styling images (`image.html`, `images/`), Responsive design & media queries (`media.html`)
- **Animations & Transitions**: CSS animations (`anime.html`), Movement/transforms (`move.html`)
- **Components & Navigation**: Navigation bars (`nav.html`), Practice projects (`project1.html`)
- **Bootstrap Basics**: Introduction (`bootstrap.html`), Buttons (`bootbtn.html`), Dropdowns (`bootdrop.html`), Responsive images (`bootimg.html`), Tables (`boottable.html`)
